# remote-computer-use v0.1.1

在 v0.1.0 基础上新增跨命令保持输入，可组合拖动、修饰键和 Esc。

## 变更

- 新增 `pointer-down/up`、`key-down/up`、`release-input`，可跨命令组合拖动、修饰键和 Esc。
- `move` 保留已按下的鼠标按钮，`key` 不释放此前显式保持的键。
- 后台跟踪保持状态，空闲 30 秒、尺寸变化、操作失败或正常断开时尽力释放。
- 文档新增面向 AI 的安装指南 `INSTALL.md`，可直接从 Release 包安装。

升级后须断开并重新连接，旧 worker 不会自动升级。

## 安装包

每个包附带同名 `.sha256` 校验文件、安装器、配置示例、文档、Skill 和第三方许可资料。

项目自身采用 MIT，第三方代码不重新许可。另提供 `remote-computer-use-0.1.1-sources.tar.gz` 及其校验文件，包含对应原生库源码、发行版补丁、构建配方和项目源码。

| 文件 | 本机要求 |
| --- | --- |
| `remote-computer-use-0.1.1-linux-amd64.tar.gz` | Linux x64，glibc 2.35+ |
| `remote-computer-use-0.1.1-linux-arm64.tar.gz` | Linux arm64，glibc 2.35+ |
| `remote-computer-use-0.1.1-darwin-arm64.tar.gz` | Apple Silicon，macOS 15.0+ |
| `remote-computer-use-0.1.1-windows-amd64.zip` | Windows x64 |

校验并解压后，Linux/macOS 执行 `./install.sh`，Windows 执行 `powershell -File .\install.ps1`。运行包无需管理员权限，远端仍需启用 VNC / RDP 服务。

## 已知风险与限制

- **macOS 未公证：** 包仅采用 ad-hoc 签名，未完成 Developer ID 签名和 Apple 公证。
- **Windows 未签名：** EXE 可能被 Defender ASR 拦截，详见 [Windows 拦截分析](../windows-asr.md)。
- **Linux ARM64：** 尚无实机验收。
- 部分滚动与 RDP 场景有限制。
