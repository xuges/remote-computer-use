# Standard license texts

These unmodified GNU license texts come from Debian/Ubuntu's
`/usr/share/common-licenses` (upstream: https://www.gnu.org/licenses/).
They supplement MSYS2 packages that publish license metadata but omit the
standard license files. Package-specific notices take precedence; installed
package metadata and source links accompany each runtime inventory.

MSYS2 documents its package license-file conventions here:
https://www.msys2.org/dev/package-licensing/
